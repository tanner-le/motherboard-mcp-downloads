# Motherboard for Claude Desktop

Download the Motherboard extension for Claude Desktop on Windows and macOS.

**[Download Motherboard 0.15.7 (.mcpb)](https://github.com/tanner-le/motherboard-mcp-downloads/releases/download/v0.15.7/Motherboard-0.15.7.mcpb)** · [Release notes](https://github.com/tanner-le/motherboard-mcp-downloads/releases/tag/v0.15.7) · [Editor’s guide](EDITOR-GUIDE.md)

## Install

1. In Claude Desktop, open **Settings → Desktop app** and select **Manage** next to **Extensions**.
2. Open **Advanced settings → Install Extension** and choose the downloaded file.
3. Choose **Continue with Google** and sign in with your Shortscut account. Once setup says **Connected to Claude**, try the first prompt below.

## Editor quickstart

Use Motherboard to find a reference before you cut, study the choices in it, and get timestamped feedback on a rough export. For more copy-and-paste prompts, including sound design and B-roll, open the [editor’s guide](EDITOR-GUIDE.md).

| When | Ask Claude |
| --- | --- |
| Choosing an opening | “Search our saved Motherboard library for three product demos that show the result before explaining it. Open the closest matches, link them, and describe each opening shot.” |
| Studying a reference | “Analyze this video [paste a TikTok, Instagram, YouTube or X link]. Map the first 15 seconds into shots, voiceover and on-screen text. Which transition could I borrow for my edit?” |
| Reviewing a rough cut | “At what timestamp can a viewer first see what the feature does? Suggest two specific trims or shot swaps that could bring that moment forward.” |

### Share a private export

- **Windows.** Ask Claude “Analyze a video from my PC.” Choose one clip in the browser and click **Analyze selected video**. If the picker doesn’t open, ask Claude for the picker link for the current job.
- **Mac.** In the Motherboard extension settings, open **Configure → Connected folders** and add your exports folder. Give Claude the file path and ask it to analyze the cut.

Local clips can be up to 30 minutes. The selected clip goes to Shortscut’s Gemini service. Keep Claude open for the result and follow-up questions.

If the sign-in tab doesn’t open, choose **Open sign-in in this browser** on the setup page. If analysis is still running, ask Claude **“Check my current video job.”**
