# Motherboard for Claude Desktop

Download the Motherboard extension for Claude Desktop on Windows and macOS.

**[Download Motherboard 0.15.7 (.mcpb)](https://github.com/tanner-le/motherboard-mcp-downloads/releases/download/v0.15.7/Motherboard-0.15.7.mcpb)** · [Release notes](https://github.com/tanner-le/motherboard-mcp-downloads/releases/tag/v0.15.7)

## Install

1. In Claude Desktop, open **Settings → Desktop app** and select **Manage** next to **Extensions**.
2. Open **Advanced settings → Install Extension** and choose the downloaded file.
3. Sign in with your Shortscut account. To check the connection, ask Claude to find a video in your Motherboard library.

On Windows, ask Claude **“Analyze a video from my PC.”** Choose a clip in the browser and click **Analyze selected video**. The extension sends the selected clip to Shortscut’s Gemini service without requiring a public video link.
